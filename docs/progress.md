## 已定案的关键决定

完整理由见 `docs/architecture.md`，此处只列结论供快速查阅。

| 项 | 结论 | 出处 |
|---|---|---|
| 项目归属 | 个人作品 / 技术预研，可开源；四条硬约束 | `AGENTS.md` §2 |
| 渲染层 | 可插拔 + 运行时一键切换，两版同步开发 | `architecture.md` §1 |
| 后端 | Next.js 全栈；业务逻辑收进 `server-core` 保留拆 NestJS 退路 | `architecture.md` §4.1 |
| app 壳子 | Next.js（随后端自动关闭） | `architecture.md` §4 |
| MVP 判据 | 端到端跑通 + 作品可展示；选型结论是副产品 | `architecture.md` §4 |
| 挂载形态 | 独立仓独立部署，经 rewrite / Multi-Zone 挂宿主站 | 会话记录 2026-08-03 |
| 主要矛盾 | **生成结果编排器，不是通用设计器**；砍功能判据见该节 | `AGENTS.md` §1.1 |
| Document | 每张画布有 `id`，是后端存储主键与一切读写入口 | `domain.md` §2.1 |
| 撤销 | **持久化**，存窄操作日志（非整树快照），以 `documentId` 为键，保留最近 200 条 | `domain.md` §4.5 |
| shape 结构 | 三段式：数据 / 纯逻辑（共享）/ 渲染绑定（两侧各写） | `architecture.md` §10 |
| 两版同步 | 由注册表完整性检查机器强制，非纪律 | `architecture.md` §10.3 |
| 版本组合 | TS 5.9.3 / Next 15.5.22 / React 19.2.8 / leafer-ui 2.2.9 | 计划文档「版本选型」 |
