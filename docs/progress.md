## 重评触发条件

达成前不重开对应议题，达成时必须重评：

- **改用 NestJS 独立后端** ← 要做多人实时协作 / 要自跑队列长任务 / 后端要被多个不同前端复用
- **升级 TypeScript 7 / Next.js 16** ← 生态工具链确认跟上后，作为独立任务
- **引入 `leafer-*` 周边插件** ← 必须单独核实其 license，主仓 MIT 不能外推
